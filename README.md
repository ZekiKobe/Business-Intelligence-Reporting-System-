# 📊 BI System (Django + React)

A modern Business Intelligence (BI) system built using **Django REST Framework** for the backend and **React.js** for the frontend.  
It provides interactive dashboards, reporting tools, and analytics for data-driven decision making.

---

## 🚀 Features

- 📈 Interactive dashboards and data visualization  
- 📊 KPI monitoring and business analytics  
- 🔐 Authentication & role-based access control  
- 🧾 Report generation (PDF / Excel export)  
- 🔄 RESTful APIs using Django REST Framework  
- ⚡ Fast and responsive UI with React  
- 🗄️ Database-driven insights  

---

## 🏗️ Tech Stack

### Backend
- Django
- Django REST Framework
- PostgreSQL / MySQL
- Pandas (optional)

### Frontend
- React.js
- Axios
- Chart.js / Recharts / ECharts
- Bootstrap / Tailwind CSS
